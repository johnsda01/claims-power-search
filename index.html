CONVERT TO SEARCHABLE TEXT

PDF, Word, and text files are converted into a text copy this app can search. Each PDF page keeps its source reference so you can jump back to the original.

Converted text files are saved on your PC, in the same folder as the originals, and are never uploaded. Each converted file is clearly labeled (for example policy.searchable.txt next to policy.pdf). If your browser does not allow writing to the folder, copies are kept in this browser instead — use Clear stored documents in step 01 to remove them.
